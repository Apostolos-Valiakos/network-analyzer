1. Overview & Deployment Topology / Επισκόπηση & Τοπολογία

EN

A full deployment involves three machines (or processes). They can share one host for development; in production they are typically separated as shown.

ΕΛ

Μια πλήρης ανάπτυξη περιλαμβάνει τρεις μηχανές (ή διεργασίες). Για ανάπτυξη μπορούν να τρέχουν στον ίδιο υπολογιστή· σε παραγωγή συνήθως διαχωρίζονται όπως φαίνεται παρακάτω.

Copy .env.example to .env in the project root and fill in all values. The backend will refuse to start if JWT_SECRET_KEY is missing.

ΕΛ

Αντιγράψτε το .env.example σε .env στη ρίζα του έργου και συμπληρώστε όλες τις τιμές. Το backend αρνείται να εκκινήσει αν απουσιάζει το JWT_SECRET_KEY.

cp .env.example .env
nano .env
VariableRequiredDescription / Περιγραφή
DATABASE_URLYespostgresql://netanalyzer:pass@localhost:5432/network_analyzer
JWT_SECRET_KEYYesRandom 32+ char string. Generate: python3 -c "import secrets; print(secrets.token_hex(32))"
INTERNAL_TOKENYesShared with Sensor VM. Must match SECRET_TOKEN on sensor.

2.6 Initialise Schema & Create Admin User / Αρχικοποίηση Σχήματος & Admin

# Initialise database tables / Δημιουργία πινάκων βάσης
python - <<'EOF'

    db.create_all()
    print("Schema created / Σχήμα δημιουργήθηκε")
EOF

# Create first admin user / Δημιουργία πρώτου χρήστη admin
python - <<'EOF'
from app import app
from models import db, User
from werkzeug.security import generate_password_hash
with app.app_context():
    db.session.add(User(
        username="admin",

        role="admin"
    ))
    db.session.commit()
    print("Admin user created / Χρήστης admin δημιουργήθηκε")
EOF
Warning / Προειδοποίηση: Change the admin password immediately after first login. / Αλλάξτε τον κωδικό admin αμέσως μετά την πρώτη σύνδεση.

3.2 Configure & Install / Διαμόρφωση & Εγκατάσταση

EN

Set VUE_APP_API_BASE_URL in .env to the Flask API address reachable from the user's browser — not 127.0.0.1 if the API is on a different machine.

ΕΛ

Ορίστε το VUE_APP_API_BASE_URL στο .env στη διεύθυνση του Flask API που προσεγγίζει ο περιηγητής του χρήστη — όχι 127.0.0.1 αν το API βρίσκεται σε άλλη μηχανή.

# .env
VUE_APP_API_BASE_URL=http://192.168.1.10:5555

npm install           # install dependencies / εγκατάσταση εξαρτήσεων
npm run dev           # development hot-reload at http://localhost:3000
npm run build         # production build
npm run start         # production server at http://0.0.0.0:3000

3.3 Optional Nginx Reverse Proxy / Προαιρετικό Nginx Reverse Proxy

# /etc/nginx/sites-available/network-analyzer
server {
    listen 80;
    server_name your.domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
    }

    location /api/ {
        rewrite ^/api(/.*)$ $1 break;
        proxy_pass http://127.0.0.1:5555;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
    }
}

sudo ln -s /etc/nginx/sites-available/network-analyzer /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

4. Sensor VM Installation / Εγκατάσταση VM Αισθητήρα (Host Files)

EN

The Sensor VM is a Linux machine on the monitored network. It runs four components: Zeek IDS (parses traffic → conn.log), dumpcap (ring-buffer PCAP capture), zeek_agent.py (batches Zeek flows to the Flask API every 2 s or 50 records), and pcap_server.py (Flask on port 5005 serving on-demand PCAP slices).

ΕΛ

Το VM αισθητήρα είναι Linux μηχανή στο παρακολουθούμενο δίκτυο. Εκτελεί τέσσερα στοιχεία: Zeek IDS (αναλύει κυκλοφορία → conn.log), dumpcap (καταγραφή PCAP σε δακτύλιο), zeek_agent.py (αποστέλλει ροές Zeek στο Flask API κάθε 2 δλ ή 50 εγγραφές), και pcap_server.py (Flask στη θύρα 5005 για τμήματα PCAP κατ' απαίτηση).

4.1 Install System Packages / Εγκατάσταση Πακέτων

sudo apt update
sudo apt install -y python3 python3-pip wireshark-common tshark nmap curl wget
pip3 install requests flask
EN: When prompted during Wireshark install — answer Yes to allow non-root packet capture, or run all sensor scripts as root.
ΕΛ: Κατά την εγκατάσταση Wireshark, απαντήστε Yes για λήψη πακέτων χωρίς root, αλλιώς εκτελείτε τα scripts ως root.

4.2 Install Zeek / Εγκατάσταση Zeek

echo 'deb http://download.opensuse.org/repositories/security:/zeek/xUbuntu_22.04/ /' \
    | sudo tee /etc/apt/sources.list.d/security:zeek.list

curl -fsSL https://download.opensuse.org/repositories/security:zeek/xUbuntu_22.04/Release.key \
    | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/security_zeek.gpg > /dev/null

sudo apt update && sudo apt install -y zeek

echo 'export PATH=$PATH:/opt/zeek/bin' >> ~/.bashrc
source ~/.bashrc
zeek --version    # verify / επαλήθευση

4.3 Copy Sensor Files / Αντιγραφή Αρχείων Αισθητήρα

EN

Copy the three files from Host Files/ to the sensor machine:

ΕΛ

Αντιγράψτε τα τρία αρχεία από τον κατάλογο Host Files/ στο VM:

# From the application server / Από τον εξυπηρετητή εφαρμογής
scp "Host Files/start_sensor.sh" \
    "Host Files/zeek_agent.py" \
    "Host Files/pcap_server.py" \
    user@sensor-ip:~/sensor/

# On sensor VM / Στο VM αισθητήρα
chmod +x ~/sensor/start_sensor.sh

4.4 Configure the Sensor / Διαμόρφωση Αισθητήρα

EN

All sensor configuration is hardcoded at the top of each file — there is no .env on the sensor machine. Edit the values before deploying.

ΕΛ

Όλη η διαμόρφωση είναι hardcoded στην αρχή κάθε αρχείου — δεν υπάρχει αρχείο .env στο VM αισθητήρα. Επεξεργαστείτε τις τιμές πριν την ανάπτυξη.

zeek_agent.py

# ─── Configuration ────────────────────────────────────────────────────────────
ZEEK_LOG_PATH = "conn.log"
HOST_API_URL  = "http://<app-server-ip>:5555/v1/ingest/zeek"
SECRET_TOKEN  = "same_value_as_INTERNAL_TOKEN_in_backend_env"
# ──────────────────────────────────────────────────────────────────────────────

pcap_server.py

# ─── Configuration ────────────────────────────────────────────────────────────
SECRET_TOKEN = "same_value_as_INTERNAL_TOKEN_in_backend_env"
# ──────────────────────────────────────────────────────────────────────────────

start_sensor.sh

# ─── Configuration ────────────────────────────────────────────────────────────
HOST_IP="<sensor-vm-ip>"        # this machine's IP — excluded from capture
SENSOR_PORTS="5000 or port 5001 or port 5005"
# ──────────────────────────────────────────────────────────────────────────────
EN: SECRET_TOKEN in both Python files must exactly match INTERNAL_TOKEN in the Flask backend .env. A mismatch causes HTTP 401 on every Zeek ingest request.
ΕΛ: Το SECRET_TOKEN και στα δύο Python αρχεία πρέπει να ταιριάζει ακριβώς με το INTERNAL_TOKEN του backend. Αναντιστοιχία προκαλεί HTTP 401 σε κάθε εισαγωγή Zeek.

4.5 Start the Sensor / Εκκίνηση Αισθητήρα

cd ~/sensor
./start_sensor.sh eth0    # replace eth0 with your interface / αντικαταστήστε με τη διεπαφή σας
Figure 2 / Σχήμα 2 – Sensor VM Internal Flow / Εσωτερική Ροή VM Αισθητήρα
  Network Interface (promiscuous / Δεπαφή δικτύου, promiscuous mode)
           │
           ├──────────────────────────────────┐
           │                                  │
  ┌────────▼────────┐                ┌────────▼────────┐
  │   Zeek IDS      │                │   dumpcap       │
  │ -C -i eth0      │                │ ring buffer     │
  │ LogAscii JSON   │                │ 500 MB / file   │
  └────────┬────────┘                │ 3 files max     │
           │ conn.log (JSON)         └────────┬────────┘
           │                                  │ generated_pcaps/
  ┌────────▼────────┐                ┌────────▼────────┐
  │ zeek_agent.py   │                │ pcap_server.py  │
  │ tail + batch    │                │ Flask :5005     │
  │ 50 flows / 2 s  │                │ GET /get-pcap   │
  └────────┬────────┘                └────────┬────────┘
           │ POST /v1/ingest/zeek              │ on-demand slice
           │ X-Internal-Token                  │ mergecap + editcap
           ▼                                   ▼
     Flask API :5555              Flask API :5555
EN: To list network interfaces: ip link show. For passive monitoring without disrupting traffic, use a SPAN port or network TAP. The -C flag disables checksum verification — required on mirror ports.
ΕΛ: Λίστα διεπαφών: ip link show. Για παθητική παρακολούθηση χρησιμοποιήστε θύρα SPAN ή network TAP. Η σημαία -C απενεργοποιεί checksum — απαραίτητο σε θύρες καθρέφτη.

6. Running as System Services / Υπηρεσίες Συστήματος (systemd)

EN

Use systemd unit files so all components restart automatically after a reboot.

ΕΛ

Χρησιμοποιήστε αρχεία μονάδας systemd ώστε όλα τα στοιχεία να επανεκκινούνται αυτόματα μετά από επανεκκίνηση.

6.1 Flask API Service

# /etc/systemd/system/netanalyzer-api.service
[Unit]
Description=Network Analyzer Flask API
After=network.target postgresql.service

[Service]
User=www-data
WorkingDirectory=/opt/network-analyzer/server
EnvironmentFile=/opt/network-analyzer/.env
ExecStart=/opt/network-analyzer/server/.venv/bin/python app.py
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

sudo systemctl daemon-reload
sudo systemctl enable --now netanalyzer-api

6.2 Nuxt Frontend Service

# /etc/systemd/system/netanalyzer-frontend.service
[Unit]
Description=Network Analyzer Nuxt Frontend
After=network.target netanalyzer-api.service

[Service]
User=www-data
WorkingDirectory=/opt/network-analyzer
EnvironmentFile=/opt/network-analyzer/.env
ExecStart=/usr/bin/npm run start
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

sudo systemctl enable --now netanalyzer-frontend

6.3 Sensor Service / Υπηρεσία Αισθητήρα

# /etc/systemd/system/netanalyzer-sensor.service
[Unit]
Description=Network Analyzer Sensor Node
After=network.target

[Service]
User=root
WorkingDirectory=/home/sensor-user/sensor
ExecStart=/bin/bash /home/sensor-user/sensor/start_sensor.sh eth0
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target

sudo systemctl enable --now netanalyzer-sensor

7. Installation Troubleshooting / Αντιμετώπιση Προβλημάτων Εγκατάστασης

Symptom / ΣύμπτωμαCause / ΑιτίαFix / Επίλυση
RuntimeError: JWT_SECRET_KEY must be set .env not loaded or missing / Δεν φορτώθηκε ή λείπει Confirm .env is in server/ with JWT_SECRET_KEY
psycopg2.OperationalError: could not connect PostgreSQL not running / Δεν τρέχει sudo systemctl start postgresql; verify with pg_isready
extension "timescaledb" does not exist TimescaleDB not installed / Δεν εγκαταστάθηκε Re-run TimescaleDB install steps / Επαναλάβετε τα βήματα εγκατάστασης
ModuleNotFoundError: No module named 'pyshark' venv not activated / Δεν ενεργοποιήθηκε venv Activate .venv; run pip install -r requirements.txt
tshark errors during analysis tshark not in PATH / Δεν βρίσκεται στο PATH which tshark; add Wireshark bin to PATH
Nuxt CORS error in browser Origin not in ALLOWED_ORIGINS Add frontend URL to ALLOWED_ORIGINS in .env
Zeek does not produce conn.log Zeek not found or wrong interface / Λάθος διεπαφή /opt/zeek/bin/zeek --version; check interface with ip a
zeek_agent.py: connection refused Wrong HOST_API_URL or Flask API down Verify Flask API is running; check HOST_API_URL
pcap_server.py returns 401 Token mismatch / Αναντιστοιχία token Copy exact same token to both .env files
dumpcap: permission denied Not in wireshark group / Δεν ανήκει στην ομάδα wireshark sudo usermod -aG wireshark $USER; log out and back in
mergecap / editcap not found wireshark-common not installed sudo apt install -y wireshark-common
npm install EACCES error Running as root or wrong npm prefix Run as normal user; npm config set prefix ~/.npm-global
