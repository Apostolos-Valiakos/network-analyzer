1. Εισαγωγή

Το Network Analyzer είναι μια πλατφόρμα ανοιχτού κώδικα που αναπτύχθηκε στο Πανεπιστήμιο Θεσσαλίας για τη βαθιά επιθεώρηση και ταξινόμηση της κυκλοφορίας δικτύου 5G και 6G. Επεξεργάζεται αρχεία καταγραφής PCAP ή ζωντανή ροή τηλεμετρίας Zeek, εφαρμόζει μη επιβλεπόμενη ομαδοποίηση μηχανικής μάθησης και αξιολόγηση ρόλων βάσει κανόνων, και προσφέρει διαδραστικά ταμπλό για ερευνητές, αναλυτές ασφαλείας και μηχανικούς δικτύων.

Η πλατφόρμα αντιμετωπίζει τρεις κύριες ερευνητικές προκλήσεις:

  1. Ορατότητα κυκλοφορίας — παροχή στατιστικών ανά ροή, κατανομή πρωτοκόλλου και διαδραστικά γραφήματα δικτύου από αυθαίρετα αρχεία PCAP.
  2. Ταξινόμηση συμπεριφοράς — αυτόματη ομαδοποίηση σημείων IP βάσει κυκλοφοριακής συμπεριφοράς με συσταδοποίηση και ανάθεση λειτουργικών ρόλων 5G/6G (UPF, AMF, gNB, UE, …) μέσω κινητήρα κανόνων.
  3. Επίγνωση πραγματικού χρόνου — ροή ζωντανών αρχείων καταγραφής Zeek σε hypertable TimescaleDB και ανάδειξη ανωμαλιών μέσω ειδοποιήσεων WebSocket.

2. Αρχιτεκτονική Συστήματος

3. Εγκατάσταση & Εκκίνηση

3.1 Προαπαιτούμενα

Πριν εκτελέσετε την πλατφόρμα, βεβαιωθείτε ότι τα παρακάτω είναι εγκατεστημένα στον κεντρικό εξυπηρετητή:

  • Python 3.11+ — χρόνος εκτέλεσης backend
  • Node.js 18+ και npm — αλυσίδα εργαλείων frontend
  • PostgreSQL 14 με ενεργοποιημένη επέκταση TimescaleDB
  • tshark / Wireshark — για αποκωδικοποίηση PCAP μέσω PyShark
  • Zeek IDS — μόνο για VM αισθητήρα, για ζωντανή τηλεμετρία
  • Nmap — μόνο για VM αισθητήρα, για σαρώσεις κατ' απαίτηση

3.2 Διαμόρφωση Περιβάλλοντος

Αντιγράψτε το .env.example σε .env στη ρίζα του έργου και συμπληρώστε όλες τις απαιτούμενες τιμές. Το backend διαβάζει αυτό το αρχείο κατά την εκκίνηση μέσω python-dotenv. Μην υποβάλετε ποτέ συμπληρωμένο .env στο σύστημα ελέγχου εκδόσεων. 

# .env (παραδείγματα τιμών — αντικαταστήστε πριν από τη χρήση)
DATABASE_URL=postgresql://user:password@localhost:5432/network_analyzer
JWT_SECRET_KEY=αλλάξτε_σε_μακρά_τυχαία_συμβολοσειρά
INTERNAL_TOKEN=αλλάξτε_εσωτερικό_token
ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
VUE_APP_API_BASE_URL=http://127.0.0.1:5555

4. Αυθεντικοποίηση

Όλες οι σελίδες εκτός από το δημόσιο Swagger UI (/apidocs) απαιτούν πιστοποιημένη σύνδεση. Η εφαρμογή χρησιμοποιεί JSON Web Tokens (JWT) με διάρκεια ισχύος 8 ωρών. Όταν λήξει το token, ο χρήστης ανακατευθύνεται αυτόματα στη σελίδα σύνδεσης.

4.1 Διαδικασία Σύνδεσης

  1. Μεταβείτε στη διεύθυνση http://<host>:3000/login.
  2. Εισαγάγετε το Όνομα χρήστη και τον Κωδικό πρόσβασης και πατήστε Sign In ή Enter.
  3. Σε επιτυχία, το JWT αποθηκεύεται στον περιηγητή και ανακατευθύνεστε στο κεντρικό ταμπλό.
  4. Η κεφαλίδα εμφανίζει το όνομά σας και κουμπί Logout που διαγράφει αμέσως το token.

Εάν εμφανιστεί σφάλμα "Invalid credentials", επαληθεύστε τα διαπιστευτήρια σας. Επικοινωνήστε με τον διαχειριστή για δημιουργία λογαριασμού ή επαναφορά κωδικού — δεν υπάρχει αυτοεξυπηρέτηση.

5. Μεταφόρτωση & Ανάλυση PCAP

Η σελίδα Analyze (/analyze) παρέχει ροή εργασίας ενός βήματος: μεταφορτώστε ένα αρχείο .pcap και λάβετε πλήρη αναφορά ανάλυσης — στατιστικά πακέτων, κατανομή πρωτοκόλλου, ανάλυση συνομιλιών, διαδραστικό γράφημα δικτύου, εξαγωγή περιόδων UE και αξιολόγηση ρόλων IP — σε μία μόνο κλήση API.

5.1 Βήμα προς Βήμα

  1. Κάντε κλικ στο πεδίο εισαγωγής αρχείου "Select .pcap file" και επιλέξτε ένα έγκυρο αρχείο PCAP από το τοπικό σας σύστημα αρχείων.
  2. Το μέγεθος του αρχείου εμφανίζεται δίπλα στο όνομά του για επιβεβαίωση.
  3. Κάντε κλικ στο Analyse. Εμφανίζεται δείκτης προόδου κατά την επεξεργασία από το backend.
  4. Μετά την ολοκλήρωση, εμφανίζεται κάρτα σύνοψης Total Packets μαζί με όλες τις ενότητες ανάλυσης.
  5. Χρησιμοποιήστε Save Roles as JSON ή Save Roles as CSV για εξαγωγή της αναφοράς αξιολόγησης ρόλων.
  6. Clear cached results διαγράφει προηγούμενα αποθηκευμένα αποτελέσματα από τον περιηγητή για νέα φρέσκια μεταφόρτωση.

5.2 Ενότητες Ανάλυσης

ΕνότηταΠεριγραφή
Total Packets Συνολικός αριθμός καταγεγραμμένων πακέτων στο αρχείο.
Protocol Distribution Γράφημα με την κατανομή TCP, UDP, GTP, SCTP, ICMP και άλλων πρωτοκόλλων.
Conversation Statistics Όγκος κυκλοφορίας, αριθμός πακέτων και bytes ανά ζεύγος IP.
Network Graph Διαδραστικό γράφημα· κόμβοι = διευθύνσεις IP, βάρος ακμής = όγκος κυκλοφορίας.
IP Role Assessment Ταξινόμηση βάσει κανόνων σε 5G NF, στοιχείο O-RAN, UE, εξωτερικό διακομιστή ή άγνωστο.
UE Sessions Εξαγωγή περιόδων UE 4G/5G — IMSI, GUTI, ανατεθείσα IPv4, χρονικές σφραγίδες.
Σημείωση: Γίνονται αποδεκτά μόνο αρχεία .pcap. Τα αρχεία PCAPNG πρέπει να μετατραπούν πρώτα με:
tshark -F pcap -r εισαγωγή.pcapng -w εξαγωγή.pcap

6. Συσταδοποίηση (Agglomerative Clustering)

Η σελίδα Clustering (/clustering) παρέχει τριβήματη ροή εργασίας για εφαρμογή ιεραρχικής συσταδοποίησης σε αρχείο PCAP που έχει ήδη μεταφορτωθεί και επεξεργαστεί από το backend.

Η συσταδοποίηση ομαδοποιεί σημεία IP βάσει της κυκλοφοριακής τους συμπεριφοράς χωρίς ανάγκη για επισημασμένα δεδομένα εκπαίδευσης (μη επιβλεπόμενη μάθηση). Η πλατφόρμα χρησιμοποιεί διαμοντελικότητα γράφου για αυτόματη πρόταση του βέλτιστου αριθμού συστάδων.

6.1 Βήμα 1 — Συσταδοποίηση

Ο οδηγός ανοίγει στο πάνελ Clustering. Το σύστημα έχει ήδη υπολογίσει προτεινόμενο αριθμό συστάδων βάσει της διαμοντελικότητας του γράφου κυκλοφορίας. Μπορείτε να αποδεχτείτε την πρόταση ή να ρυθμίσετε χειροκίνητα τον αριθμό με το ρυθμιστικό. Το δενδρόγραμμα απεικονίζει τη συγχώνευση ομάδων σε κάθε βήμα· οι εκτοπισμένες IP σημειώνονται ως ανωμαλίες.

6.2 Βήμα 2 — Αξιολόγηση

Επιλέξτε συστάδα από τη λίστα για αξιολόγηση των μελών της. Ο κινητήρας αξιολόγησης συσχετίζει χρήση θύρας, μοτίβα σύνδεσης και όγκους δεδομένων για ανάθεση πιθανού λειτουργικού ρόλου 5G/6G σε κάθε IP. Κάντε κλικ στο Start Analysis με την επιθυμητή συστάδα επιλεγμένη.

6.3 Βήμα 3 — Αποτελέσματα

Το τελικό πάνελ αποτελεσμάτων εμφανίζει πλήρη αξιολόγηση ρόλων για όλες τις ομαδοποιημένες IP. Κατεβάστε το PCAP ή εξαγάγετε την αναφορά ρόλων ως JSON ή CSV.

7. Ανάλυση Ροής Πραγματικού Χρόνου

Η σελίδα Real Time (/realTime) επιτρέπει ζωντανή λήψη πακέτων από απομακρυσμένη πηγή WebSocket. Η πλατφόρμα λαμβάνει τμήματα δεδομένων κωδικοποιημένα σε Base64 και τα συναρμολογεί στον εξυπηρετητή σε συνεκτικό αρχείο PCAP για άμεση ανάλυση.

7.1 Ροή Εργασίας

  1. Εισαγάγετε τη Διεύθυνση WebSocket του απομακρυσμένου πράκτορα σύλληψης (π.χ. ws://192.168.1.10:8080).
  2. Κάντε κλικ στο Connect. Ο δείκτης κατάστασης γίνεται πράσινος και εμφανίζει "Connected".
  3. Στο πάνελ Capture Controls:
    • Κάντε κλικ στο Get Interfaces για εμφάνιση διαθέσιμων διεπαφών δικτύου στον απομακρυσμένο πράκτορα.
    • Επιλέξτε διεπαφή από το αναπτυσσόμενο μενού.
    • Κάντε κλικ στο Start Capture για έναρξη καταγραφής.
  4. Όταν συγκεντρωθούν αρκετά δεδομένα, κάντε κλικ στο Generate PCAP (ενεργό μόνο κατά την καταγραφή). Ο εξυπηρετητής οριστικοποιεί το αρχείο και εμφανίζεται σύνδεσμος λήψης.
  5. Προαιρετικά, αποστολή του συναρμολογημένου PCAP απευθείας στον αγωγό ανάλυσης.
Προειδοποίηση: Η πηγή WebSocket πρέπει να είναι προσβάσιμη από τον περιηγητή. Ενδέχεται να χρειαστεί ρύθμιση τείχους προστασίας και NAT για αναπτύξεις διαφορετικών δικτύων.

8. Συνεχής Παρακολούθηση

Το ταμπλό Continuous Monitoring (/continuous_monitoring) παρέχει ζωντανή θέαση των ροών δικτύου που αποθηκεύονται στο hypertable TimescaleDB (flow_statistics). Τα δεδομένα φτάνουν από το VM αισθητήρα μέσω του πράκτορα Zeek και του endpoint POST /v1/ingest/zeek.

8.1 Επιλογή Χρονοπλαισίου

Επιλέξτε ημερομηνία έναρξης και λήξης για αναζήτηση ιστορικών ροών ή ενεργοποιήστε τη Ζωντανή Λειτουργία (Live Mode) για συνεχή ανανέωση δεδομένων σε σταθερό διάστημα. Κάντε κλικ στο Apply για ανάκτηση.

8.2 Πίνακας Στατιστικών Ροών

Ταξινομήσιμος, με φίλτρα, πίνακας που εμφανίζει όλες τις καταγεγραμμένες συνδέσεις: IP προέλευσης/προορισμού, θύρες, πρωτόκολλο, bytes αποστολής/παραλαβής, αριθμό πακέτων και χρονική σφραγίδα. Κάντε κλικ σε οποιαδήποτε επικεφαλίδα στήλης για ταξινόμηση.

8.3 Ειδοποιήσεις Ανωμαλιών

Το backend αξιολογεί κάθε εισερχόμενη δέσμη ροών και αποστέλλει ειδοποιήσεις WebSocket σε όλους τους συνδεδεμένους πελάτες όταν ανιχνεύει:

  • Μαζικές μεταφορές δεδομένων (> 5 MB σε μία ροή)
  • Πλημμύρες πακέτων (> 5 000 πακέτα σε μία ροή)
  • Απορριφθείσες συνδέσεις (TCP RST / ICMP unreachable)

Οι ειδοποιήσεις εμφανίζονται ως έγχρωμες ειδοποιήσεις snackbar στον περιηγητή και καταγράφονται επίσης στον εξυπηρετητή.

8.4 Ενσωμάτωση Σάρωσης Nmap

Κάντε κλικ στο Trigger Nmap Scan για εκκίνηση σάρωσης Nmap κατ' απαίτηση στο VM αισθητήρα. Τα αποτελέσματα επιστρέφονται ως δομημένο αντικείμενο JSON και εμφανίζονται στο ταμπλό.

8.5 Εξαγωγή

Χρησιμοποιήστε τα κουμπιά Download CSV / JSON για εξαγωγή του τρέχοντος παραθύρου ροών για εκτός σύνδεσης ανάλυση.

9. Αναφορά API

Διαδραστικό Swagger UI σερβίρεται από το Flask backend στη διεύθυνση http://<host>:5555/apidocs. Τεκμηριώνει κάθε endpoint με παραμέτρους, σώματα αιτημάτων, σχήματα απόκρισης και απαιτήσεις αυθεντικοποίησης. Δεν απαιτείται σύνδεση για περιήγηση. Τα endpoints που απαιτούν JWT token σημειώνονται με εικονίδιο κλειδαριάς. Χρησιμοποιήστε το κουμπί Authorize για ζωντανή διαδραστική δοκιμή.

9.3 Περιορισμός Ρυθμού

Το Flask-Limiter εφαρμόζει ανά-IP όρια ρυθμού για προστασία του εξυπηρετητή. Υπέρβαση του ορίου επιστρέφει HTTP 429 Too Many Requests. Επικοινωνήστε με τον διαχειριστή για τα τρέχοντα όρια.

10. Διαχείριση

Το πάνελ Admin (/admin) είναι προσβάσιμο μόνο σε χρήστες με ρόλο admin.

10.1 Διαχείριση Χρηστών

  • Δημιουργία νέων λογαριασμών χρηστών με όνομα, κωδικό πρόσβασης και ρόλο.
  • Απενεργοποίηση ή διαγραφή υφιστάμενων λογαριασμών.
  • Οι κωδικοί αποθηκεύονται ως bcrypt hashes — ποτέ σε απλό κείμενο.

10.2 Επισκόπηση Συστήματος

  • Προβολή όλων των μεταφορτωμένων αρχείων PCAP, κατάστασης ανάλυσης και χρονικών σφραγίδων.
  • Προβολή αποθηκευμένων στιγμιότυπων ρόλων και αποτελεσμάτων συσταδοποίησης.
  • Εκκαθάριση παλαιών αρχείων ή εγγραφών βάσης δεδομένων για διαχείριση αποθηκευτικού χώρου.
Σημείωση Ασφαλείας: Το X-Internal-Token που χρησιμοποιεί το VM αισθητήρα πρέπει να παραμένει μυστικό και να ανανεώνεται τακτικά. Αποθηκεύστε το αποκλειστικά στο .env — ποτέ hardcoded στον πηγαίο κώδικα ούτε σε σύστημα ελέγχου εκδόσεων.
