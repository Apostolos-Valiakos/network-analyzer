1. Introduction / Εισαγωγή

EN

Network Analyzer is an open-source research platform developed at the University of Thessaly for the deep inspection and classification of 5G and 6G network traffic. It ingests raw PCAP captures or a live Zeek telemetry stream, applies unsupervised machine-learning clustering and rule-based role assessment, and delivers interactive dashboards for researchers, security analysts, and network engineers.

The platform addresses three primary research challenges:

  1. Traffic visibility — providing per-flow statistics, protocol distribution, and interactive network graphs from arbitrary PCAP files.
  2. Behavioural classification — automatically grouping IP endpoints by traffic behaviour using agglomerative clustering and assigning 5G/6G functional roles (UPF, AMF, gNB, UE, …) using a rule-based engine.
  3. Real-time situational awareness — streaming live Zeek connection logs into a TimescaleDB hypertable and surfacing anomalies via WebSocket-pushed alerts.
ΕΛ

Το Network Analyzer είναι μια πλατφόρμα ανοιχτού κώδικα που αναπτύχθηκε στο Πανεπιστήμιο Θεσσαλίας για τη βαθιά επιθεώρηση και ταξινόμηση της κυκλοφορίας δικτύου 5G και 6G. Επεξεργάζεται αρχεία PCAP ή ζωντανή ροή τηλεμετρίας Zeek, εφαρμόζει μη επιβλεπόμενη ομαδοποίηση μηχανικής μάθησης και αξιολόγηση ρόλων βάσει κανόνων, προσφέροντας διαδραστικά ταμπλό για ερευνητές, αναλυτές ασφαλείας και μηχανικούς δικτύων.

Η πλατφόρμα αντιμετωπίζει τρεις κύριες ερευνητικές προκλήσεις:

  1. Ορατότητα κυκλοφορίας — στατιστικά ανά ροή, κατανομή πρωτοκόλλου και διαδραστικά γραφήματα δικτύου.
  2. Ταξινόμηση συμπεριφοράς — αυτόματη ομαδοποίηση IP σημείων με συσταδοποίηση και ανάθεση λειτουργικών ρόλων 5G/6G.
  3. Επίγνωση πραγματικού χρόνου — ζωντανή ροή αρχείων καταγραφής Zeek και ειδοποιήσεις ανωμαλιών μέσω WebSocket.

EN

3. Installation & Start-Up / Εγκατάσταση & Εκκίνηση

3.1 Prerequisites / Προαπαιτούμενα

EN

Before running the platform, ensure the following are installed on the server host:

  • Python 3.11+ — backend runtime
  • Node.js 18+ and npm — frontend build toolchain
  • PostgreSQL 14 with the TimescaleDB extension enabled
  • tshark / Wireshark (for PyShark-based PCAP decoding)
  • Zeek IDS (Sensor VM only — for live telemetry)
  • Nmap (Sensor VM only — for on-demand network scans)
ΕΛ

Πριν εκτελέσετε την πλατφόρμα βεβαιωθείτε ότι τα παρακάτω είναι εγκατεστημένα στον κεντρικό εξυπηρετητή:

  • Python 3.11+ — χρόνος εκτέλεσης backend
  • Node.js 18+ και npm — αλυσίδα εργαλείων frontend
  • PostgreSQL 14 με ενεργοποιημένη επέκταση TimescaleDB
  • tshark / Wireshark για αποκωδικοποίηση PCAP
  • Zeek IDS (μόνο Sensor VM)
  • Nmap (μόνο Sensor VM)

3.2 Environment Configuration / Διαμόρφωση Περιβάλλοντος

EN

Copy .env.example to .env in the project root and fill in all required values. The backend reads this file at startup via python-dotenv. Never commit a populated .env to version control.

ΕΛ

Αντιγράψτε το .env.example σε .env στη ρίζα του έργου και συμπληρώστε όλες τις απαιτούμενες τιμές. Μην υποβάλετε ποτέ συμπληρωμένο .env στο σύστημα ελέγχου εκδόσεων.

# .env (example values — replace before use)
DATABASE_URL=postgresql://user:password@localhost:5432/network_analyzer
JWT_SECRET_KEY=change_me_to_a_long_random_string
INTERNAL_TOKEN=change_me_internal_token
ALLOWED_ORIGINS=http://localhost:3000,http://127.0.0.1:3000
VUE_APP_API_BASE_URL=http://127.0.0.1:5555

3.3 Database Initialisation / Αρχικοποίηση Βάσης Δεδομένων

# Create the database and enable TimescaleDB
psql -U postgres -c "CREATE DATABASE network_analyzer;"
psql -U postgres -d network_analyzer -c "CREATE EXTENSION IF NOT EXISTS timescaledb;"

# Apply the ORM schema (run from the server/ directory)
cd server
python -c "from models import db; from app import app; app.app_context().push(); db.create_all()"

3.4 Starting the Backend / Εκκίνηση Backend

# From the project root
cd server
pip install -r requirements.txt
python app.py
# Server listens on http://0.0.0.0:5555

3.5 Starting the Frontend / Εκκίνηση Frontend

# From the project root
npm install
npm run dev       # development — hot-reload on http://localhost:3000
npm run build     # production build
npm run start     # production server
Tip / Συμβουλή: For a quick local setup, start the backend first and then the frontend. The Nuxt dev server proxies API calls to http://127.0.0.1:5555 as configured in nuxt.config.js.

Για γρήγορη τοπική εγκατάσταση, ξεκινήστε πρώτα το backend και έπειτα το frontend. Ο Nuxt dev server μεταβιβάζει κλήσεις API στο http://127.0.0.1:5555 όπως ορίζεται στο nuxt.config.js.

4. Authentication / Αυθεντικοποίηση

EN

All pages except the public Swagger UI (/apidocs) require an authenticated session. The application uses JSON Web Tokens (JWT) with an 8-hour expiry. When the token expires the user is redirected to the login page automatically.

4.1 Logging In / Σύνδεση

  1. Navigate to http://<host>:3000/login.
  2. Enter your Username and Password and press Sign In or hit Enter.
  3. On success, the JWT is stored in the browser and you are redirected to the home dashboard.
  4. The header displays your username and a Logout button that clears the token immediately.

If you see an "Invalid credentials" error, verify your username and password. Contact your system administrator for account creation or password resets — there is no self-service registration.

ΕΛ

Όλες οι σελίδες εκτός από το δημόσιο Swagger UI (/apidocs) απαιτούν πιστοποιημένη σύνδεση. Η εφαρμογή χρησιμοποιεί JWT με διάρκεια 8 ωρών. Όταν λήξει το token, ο χρήστης ανακατευθύνεται αυτόματα στη σελίδα σύνδεσης.

  1. Μεταβείτε στη διεύθυνση http://<host>:3000/login.
  2. Εισαγάγετε το Όνομα χρήστη και τον Κωδικό πρόσβασης και πατήστε Sign In.
  3. Σε επιτυχία, το JWT αποθηκεύεται στον περιηγητή και ανακατευθύνεστε στο κεντρικό ταμπλό.
  4. Η κεφαλίδα εμφανίζει το όνομά σας και κουμπί Logout που διαγράφει αμέσως το token.

Εάν εμφανιστεί σφάλμα "Invalid credentials", επαληθεύστε τα διαπιστευτήριά σας. Επικοινωνήστε με τον διαχειριστή για δημιουργία λογαριασμού ή επαναφορά κωδικού.

5. PCAP Upload & Analysis / Μεταφόρτωση & Ανάλυση PCAP

EN

The Analyze page (/analyze) provides a one-step workflow: upload a .pcap file and receive a comprehensive analysis report — packet statistics, protocol distribution, conversation breakdown, interactive network graph, UE session extraction, and IP role assessment — all in a single API call.

Step-by-step / Βήμα προς βήμα

  1. Click the file-input field labelled "Select .pcap file" and choose a valid PCAP file from your local filesystem.
  2. The file size is shown next to the filename for confirmation.
  3. Click Analyse. A progress indicator appears while the backend processes the capture.
  4. Once complete, the Total Packets summary card appears along with all analysis sections (see below).
  5. Use Save Roles as JSON or Save Roles as CSV to export the role-assessment report for downstream tooling.
  6. Clear cached results removes the browser-stored previous results so a fresh upload starts from scratch.
ΕΛ

Η σελίδα Analyze (/analyze) παρέχει ροή εργασίας ενός βήματος: μεταφορτώστε ένα αρχείο .pcap και λάβετε αναφορά ανάλυσης — στατιστικά πακέτων, κατανομή πρωτοκόλλου, ανάλυση συνομιλιών, διαδραστικό γράφημα δικτύου, εξαγωγή περιόδων UE και αξιολόγηση ρόλων IP.

  1. Κάντε κλικ στο πεδίο εισαγωγής αρχείου "Select .pcap file" και επιλέξτε ένα έγκυρο αρχείο PCAP.
  2. Το μέγεθος του αρχείου εμφανίζεται δίπλα στο όνομά του.
  3. Κάντε κλικ στο Analyse. Εμφανίζεται δείκτης προόδου.
  4. Μετά την ολοκλήρωση εμφανίζεται κάρτα σύνοψης Total Packets και όλες οι ενότητες ανάλυσης.
  5. Εξαγωγή αναφοράς ρόλων με Save Roles as JSON / CSV.
  6. Clear cached results διαγράφει προηγούμενα αποτελέσματα από τον περιηγητή.

6. Agglomerative Clustering / Συσταδοποίηση

EN

The Clustering page (/clustering) exposes an advanced three-step workflow for applying hierarchical agglomerative clustering to a PCAP that has already been uploaded and processed by the backend.

Clustering groups IP endpoints by their traffic behaviour without requiring labelled training data (unsupervised learning). The platform uses graph modularity to automatically suggest the optimal number of clusters, so analysts do not need to guess.

Step 1 — Clustering

The stepper opens on the Clustering panel. The system has already computed a suggested cluster count based on the modularity score of the traffic graph. You may accept this suggestion or manually adjust the Number of Clusters slider. The dendrogram visualises how groups merge at each agglomerative linkage step; outlier IPs are flagged as anomalies.

Step 2 — Profiling

Select a cluster from the list to profile its member IPs. The profiling engine correlates port usage, connection patterns, and data volumes to assign each IP a probable 5G/6G functional role. Click Start Analysis with the desired cluster selected.

Step 3 — Results

The final results panel shows the complete role assessment for all clustered IPs. Download the PCAP for this session or export the role report as JSON or CSV.

ΕΛ

Η σελίδα Clustering (/clustering) παρέχει τριβήματη ροή εργασίας για ιεραρχική συσταδοποίηση σε PCAP που έχει ήδη μεταφορτωθεί.

Η συσταδοποίηση ομαδοποιεί τα σημεία IP βάσει της κυκλοφοριακής τους συμπεριφοράς χωρίς ετικέτες εκπαίδευσης (μη επιβλεπόμενη μάθηση). Η πλατφόρμα χρησιμοποιεί διαμοντελικότητα γράφου για αυτόματη πρόταση του βέλτιστου αριθμού συστάδων.

Βήμα 1 — Συσταδοποίηση

Ο οδηγός ανοίγει στο πάνελ Clustering. Μπορείτε να αποδεχτείτε την πρόταση αριθμού συστάδων ή να ρυθμίσετε χειροκίνητα τον αριθμό. Το δενδρόγραμμα απεικονίζει τη συγχώνευση ομάδων· οι εκτοπισμένες IP σημειώνονται ως ανωμαλίες.

Βήμα 2 — Αξιολόγηση

Επιλέξτε συστάδα για αξιολόγηση. Ο κινητήρας συνδυάζει χρήση θύρας, μοτίβα σύνδεσης και όγκο δεδομένων για ανάθεση πιθανού ρόλου 5G/6G σε κάθε IP.

Βήμα 3 — Αποτελέσματα

Το τελικό πάνελ εμφανίζει πλήρη αξιολόγηση ρόλων. Εξαγωγή σε JSON ή CSV.

7. Real-Time Streaming Analysis / Ανάλυση Ροής Πραγματικού Χρόνου

EN

The Real Time page (/realTime) enables live packet capture from a remote WebSocket source. This is designed for scenarios where a network tap or sniffer streams raw packet data in Base64-encoded chunks to the platform, which reassembles them server-side into a coherent PCAP file.

Workflow

  1. Enter the WebSocket URL of the remote capture agent in the text field (e.g. ws://192.168.1.10:8080).
  2. Click Connect. The status indicator turns green and shows "Connected".
  3. Use the Capture Controls panel:
    • Click Get Interfaces to retrieve available network interfaces from the remote agent.
    • Select an interface from the dropdown.
    • Click Start Capture to begin recording.
  4. When sufficient data is collected, click Generate PCAP (button is active only while capturing). The backend finalises the file and a download link appears.
  5. Optionally send the assembled PCAP directly into the analysis pipeline from this page.
ΕΛ

Η σελίδα Real Time (/realTime) επιτρέπει ζωντανή λήψη πακέτων από απομακρυσμένη πηγή WebSocket. Ο διακομιστής λαμβάνει τμήματα δεδομένων κωδικοποιημένα σε Base64 και τα συναρμολογεί σε αρχείο PCAP.

  1. Εισαγάγετε τη διεύθυνση WebSocket του απομακρυσμένου πράκτορα σύλληψης (π.χ. ws://192.168.1.10:8080).
  2. Κάντε κλικ στο Connect. Ο δείκτης κατάστασης γίνεται πράσινος.
  3. Επιλέξτε διεπαφή δικτύου και κάντε κλικ στο Start Capture.
  4. Όταν συγκεντρωθούν αρκετά δεδομένα, κάντε κλικ στο Generate PCAP. Εμφανίζεται σύνδεσμος λήψης.
Warning / Προειδοποίηση: The WebSocket source must be reachable from the browser (not just from the Flask server) for the direct browser connection mode. Firewall rules and NAT may need to be adjusted.

Η πηγή WebSocket πρέπει να είναι προσβάσιμη από τον περιηγητή. Ρυθμίστε αναλόγως τα τείχη προστασίας και NAT.

8. Continuous Monitoring / Συνεχής Παρακολούθηση

EN

The Continuous Monitoring dashboard (/continuous_monitoring) provides a live view of network flows stored in the TimescaleDB hypertable (flow_statistics). Data arrives from the Host Sensor VM via the Zeek agent and the POST /v1/ingest/zeek endpoint.

8.1 Timeframe Selection

Choose a start and end datetime to query historical flows, or enable Live Mode (toggle) to continuously refresh the data at a fixed interval. Click Apply to fetch.

8.2 Flow Statistics Table

A sortable, filterable table shows all recorded connections: source IP, destination IP, source/destination ports, protocol, bytes sent/received, packet count, and timestamp. Click any column header to sort ascending/descending.

8.3 Anomaly Alerts

The backend evaluates each ingested batch of flows and pushes WebSocket alerts to all connected clients when it detects:

  • Massive data transfers (> 5 MB in a single flow)
  • Packet floods (> 5 000 packets in a single flow)
  • Rejected connections (TCP RST / ICMP unreachable)

Alerts appear as coloured snackbar notifications in the browser and are also logged server-side.

8.4 Nmap Scan Integration

Click Trigger Nmap Scan to instruct the Sensor VM to run an on-demand Nmap scan of the monitored subnet. Results are returned as a structured JSON object and displayed in the dashboard.

8.5 Export

Use the Download CSV / JSON buttons to export the currently displayed flow window for offline analysis.

ΕΛ

Το ταμπλό Continuous Monitoring (/continuous_monitoring) παρέχει ζωντανή θέαση ροών που αποθηκεύονται στο hypertable TimescaleDB. Τα δεδομένα φτάνουν από τον Sensor VM μέσω του πράκτορα Zeek.

  • Επιλογή χρονοπλαισίου — επιλέξτε εύρος ημερομηνιών ή ενεργοποιήστε τη Ζωντανή Λειτουργία.
  • Πίνακας ροών — ταξινομήσιμος, με φίλτρα, για όλες τις ηχογραφημένες συνδέσεις.
  • Ειδοποιήσεις ανωμαλιών — μεταδίδονται μέσω WebSocket όταν ανιχνευτούν μαζικές μεταφορές, πλημμύρες πακέτων ή απορρίψεις.
  • Σάρωση Nmap — εκτελέστε σάρωση on-demand από τον Sensor VM.
  • Εξαγωγή — λήψη CSV ή JSON για εκτός σύνδεσης ανάλυση.

9.3 Rate Limiting / Περιορισμός Ρυθμού

EN

Flask-Limiter enforces per-IP rate limits to protect the server from abuse. Exceeding the limit returns HTTP 429 Too Many Requests. The default limits are configured in the server environment; consult the administrator for current thresholds.

ΕΛ

Το Flask-Limiter εφαρμόζει ανά-IP όρια ρυθμού. Υπέρβαση επιστρέφει HTTP 429 Too Many Requests. Επικοινωνήστε με τον διαχειριστή για τα τρέχοντα όρια.

10. Administration / Διαχείριση

EN

The Admin panel (/admin) is accessible only to users with the admin role. It provides user management and system monitoring capabilities.

User Management

  • Create new user accounts by supplying a username, password, and role.
  • Deactivate or delete existing accounts.
  • Passwords are stored as bcrypt hashes — they are never stored in plain text.

System Overview

  • View all uploaded PCAP files, their analysis status, and timestamps.
  • View stored role snapshots and cluster results.
  • Purge old files or database records as needed for storage management.
ΕΛ

Το πάνελ Admin (/admin) είναι προσβάσιμο μόνο σε χρήστες με ρόλο admin.

  • Δημιουργία νέων λογαριασμών χρηστών με όνομα, κωδικό και ρόλο.
  • Απενεργοποίηση ή διαγραφή υφιστάμενων λογαριασμών.
  • Οι κωδικοί αποθηκεύονται ως bcrypt hashes — ποτέ σε απλό κείμενο.
  • Επισκόπηση αναρτημένων PCAP, ρόλων, συστάδων και εκκαθάριση εγγραφών.
Security Note / Σημείωση Ασφαλείας: The X-Internal-Token header used by the Sensor VM must be kept secret and rotated regularly. Store it only in the .env file — never hardcode it in source code or commit it to version control.

Το token εσωτερικής επικοινωνίας X-Internal-Token πρέπει να παραμένει μυστικό και να ανανεώνεται τακτικά. Αποθηκεύστε το μόνο στο .env.

11. Troubleshooting / Αντιμετώπιση Προβλημάτων

Symptom / Σύμπτωμα Likely Cause / Πιθανή Αιτία Fix / Επίλυση
Login returns "Invalid credentials" Wrong username/password or account disabled Verify credentials; ask admin to reset or re-enable account
Upload fails with 413 PCAP file exceeds server max upload size Increase MAX_CONTENT_LENGTH in app.py or split the PCAP
Analysis hangs indefinitely tshark not installed or not in PATH Install Wireshark/tshark and verify with tshark --version
Database connection error at startup DATABASE_URL not set or PostgreSQL not running Check .env; verify PostgreSQL service with pg_isready
TimescaleDB extension missing Extension not installed in the database Run CREATE EXTENSION IF NOT EXISTS timescaledb; as superuser
WebSocket connection refused (Real Time page) Remote capture agent not running or firewall blocking Start the remote agent; open the WebSocket port in the firewall
Zeek ingest returns 401 Incorrect or missing X-Internal-Token Ensure Sensor VM .env matches server INTERNAL_TOKEN
Rate limit 429 on API Too many requests from client IP Reduce request frequency or ask admin to raise the limit
Frontend shows blank page after login CORS mismatch — frontend origin not in ALLOWED_ORIGINS Add the frontend URL to ALLOWED_ORIGINS in .env
Clustering page shows no dendrogram PCAP has too few unique IP addresses (< 2) Use a PCAP with more varied traffic for meaningful clustering

12. Glossary / Γλωσσάριο

Term Definition (EN) Ορισμός (ΕΛ)
PCAP Packet CAPture — binary file format for network traffic recordings. Αρχείο δυαδικής μορφής για εγγραφές κυκλοφορίας δικτύου.
JWT JSON Web Token — compact, signed token used for authentication. Μικρό υπογεγραμμένο token για αυθεντικοποίηση.
5G NF 5G Network Function — logical component of the 5G Core (e.g. AMF, UPF, SMF). Λογικό στοιχείο του 5G Core (π.χ. AMF, UPF, SMF).
UE User Equipment — mobile device connected to the network (phone, tablet, IoT). Κινητή συσκευή συνδεδεμένη στο δίκτυο.
gNB Next-Generation NodeB — 5G base station. Σταθμός βάσης 5G.
GTP GPRS Tunnelling Protocol — encapsulation protocol used in 4G/5G user plane. Πρωτόκολλο τούνελ χρησιμοποιούμενο στο επίπεδο χρήστη 4G/5G.
Zeek Network analysis framework that generates structured connection logs from live traffic. Πλαίσιο ανάλυσης δικτύου που παράγει δομημένα αρχεία καταγραφής.
TimescaleDB PostgreSQL extension optimised for time-series data; adds hypertables and time-bucketing. Επέκταση PostgreSQL βελτιστοποιημένη για χρονοσειρές.
Agglomerative Clustering Bottom-up hierarchical clustering that merges the two most similar clusters at each step. Ιεραρχική συσταδοποίηση από κάτω προς τα πάνω.
Modularity Graph-theory metric that measures the quality of a community partition. Μετρική θεωρίας γράφων για την ποιότητα μιας διαμέρισης κοινότητας.
Anomaly IP address or flow that deviates significantly from normal behaviour. Διεύθυνση IP ή ροή που αποκλίνει σημαντικά από την κανονική συμπεριφορά.
O-RAN Open Radio Access Network — open-interface radio access architecture for 5G/6G. Ανοικτή αρχιτεκτονική δικτύου ραδιοπρόσβασης για 5G/6G.
IMSI International Mobile Subscriber Identity — unique 15-digit identifier for a SIM. Διεθνής Ταυτότητα Κινητού Συνδρομητή — μοναδικός αριθμός 15 ψηφίων.
GUTI Globally Unique Temporary Identifier — privacy-preserving temporary UE identifier. Προσωρινή ταυτότητα UE για διαφύλαξη ιδιωτικότητας.
Hypertable TimescaleDB table automatically partitioned by time for high-throughput time-series writes. Πίνακας TimescaleDB αυτόματα κατακερματισμένος ανά χρόνο.
Nmap Network Mapper — open-source tool for network discovery and security auditing. Εργαλείο ανακάλυψης δικτύου και ελέγχου ασφαλείας ανοικτού κώδικα.
