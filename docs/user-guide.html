User Guide

Using PENM

For analysts and operators using the web application: every page, what it shows and how to use it.

1. Getting started

PENM (Privacy Enhanced Network Monitor) analyses 5G/6G network traffic. It identifies what each IP address is (gNB, AMF, UPF, UE, O-RAN components…), extracts UE identities, groups devices by behaviour, measures privacy risk, and monitors a live network through a capture sensor.

  1. Open the address your administrator gave you (http://<server>) and log in. Accounts are created by an administrator; there is no self-registration.
  2. The header links to every page: Home, Analyze, History, Real Time, Monitoring, About, Contact, API Docs, and Users for admins. The sun/moon button switches light and dark theme.
  3. A login lasts 8 hours. After that, or after Logout, you are sent back to the login page.

2. Analyze a capture

  1. On Analyze, choose a .pcap file and press Analyse. Files must have the .pcap extension (pcapng content is fine). At most 5 uploads per minute.
  2. PENM stores the file, counts packets and conversations, assigns a role to every IP address, extracts UE identities (IMSI, 5G-TMSI, PDU session, UE address) and builds privacy records. A large capture (hundreds of thousands of packets) takes about 20 seconds.
  3. The page shows the Total Packets and, when the capture has host data, the privacy panel.
  4. Save Roles as JSON / as CSV download the role summary. Clear cached results forgets the last result kept in your browser.

The role table, reasoning and network graph for this file are in History (View Results) and on the Clustering page (Open in Clustering).

If part of the analysis failed while the rest worked (for example the UE extraction), a yellow box lists what is missing. The rest of the result is still valid.

Privacy panel

Shows how identifiable the hosts in the capture are, and how much anonymisation would help:

  • Choose the Identifiers (quasi-identifiers) and the Sensitive Attribute.
  • Optionally choose transformations: Pseudonymize Columns (mode and technique: SHA256 with salt, HMAC-SHA256, format-preserving IP, random tokens), Generalize Columns (with a profile per column) and Suppress Columns / a suppression threshold.
  • Compute Privacy Metrics shows the metrics before and after the transformations, suggestions, and a preview of the transformed records. The info button explains each technique.

The status shows COMPLETED, PROCESSING or ERROR. A re-analysis that fails marks the file ERROR and keeps the previous result. Delete removes the file from the server and cannot be undone.

4. Clustering and roles

Opened from History, from Real Time (Analyze), or with /clustering?id=<file>. Three steps:

  1. Clustering. PENM suggests a number of clusters from the traffic graph's modularity, and draws the devices coloured by cluster. Change Number of Clusters to recompute. Clusters with very few members are flagged as anomalous. Select Cluster(s) to analyze picks the devices for the next step.
  2. Profiling. Start Rule Based Analysis assigns each selected IP a role, with a confidence and the evidence behind it (see section 8).
  3. Results. Download Roles (JSON or CSV), Download PCAP File, Previous, Start Over.

The page also shows the download link and API address of the capture. Each clustering result is saved in History; if it could not be saved, a yellow box says so.

5. Real Time capture

Captures live packets from the sensor's packet stream in your browser, saves them as a pcap, and analyses it.

  1. Check the WebSocket URL (pre-filled with the sensor's address) and press Connect. The status turns green.
  2. Get Interfaces lists the sensor's interfaces; choose one in Select Interface. Stop the capture before switching interfaces.
  3. Start begins capturing. The metrics show packets and size, the packet log the latest packets, and the graph preview the devices seen so far.
  4. Generate PCAP (at the top, while capturing) saves what has been captured so far and keeps capturing; a Download PCAP link appears.
  5. Visualize builds the network graph from the capture. Analyze stops the capture, saves it and opens it in Clustering.
  6. Stop stops capturing; Clear resets the counters and graph.

Your browser connects to the sensor directly, so its port 5002 must be reachable from your computer. Only the address the application was built for is allowed; ask your administrator if the sensor moved.

6. Continuous Monitoring

A dashboard of the network the sensor watches, from flow records (Zeek) stored by the backend.

Statistics and downloads

  • Timeframe: set Start Time and End Time and press Apply, or turn on Live Mode to add new flows as they arrive.
  • Cards and charts: total packets and flow records; traffic trend over time, protocol distribution, top talkers, connection states and the conversation topology (refreshed every minute).
  • Network Flow Logs: every flow in the timeframe; Search IP or Protocol filters it.
  • Pcap downloads: Headers Only downloads the timeframe's traffic with headers only (no payloads); Full Payload downloads the sensor's most recent capture file with payloads. Capture history is limited (usually 6–24 hours).
  • Export: CSV or JSON exports the timeframe's flows; Limit caps the number of rows (blank = all).

Live analysis

Every few minutes (5 by default) the server takes a snapshot of the sensor's latest traffic and assigns roles to every device in it. Run Analysis on Latest Slice analyses the newest snapshot and shows the Identified Roles. Devices that match no known role are reported to the XTRUST-6G alert feed. If it says no snapshot is available yet, wait a few minutes or ask your administrator to check the sensor.

Nmap scans

Scans devices from the sensor, to see their open ports and services:

  1. Choose a profile: Fast Scan (100 common ports), Deep Version Scan (service versions) or Vulnerability Scan (10,000 ports plus known vulnerabilities; slowest).
  2. Enter a Custom Target (address or range such as 192.168.100.1/26), or leave it blank to scan the devices found by the last live analysis.
  3. Launch Background Scan. Results appear per host when the scan finishes; Download CSV saves them.

Scans send active traffic. Only scan networks you are allowed to test. There is one scan at a time for all users: a new scan replaces the previous results. At most 5 scan requests per minute.

7. Users (admins)

Users lists all accounts. Create one with Username, Password (min 8 characters) and optionally Admin; delete with the bin icon. Admins see all users' files in History and can manage accounts; other users see only their own files.

8. What the roles mean

Roles come from evidence in the traffic, for example which side listens on a protocol's well-known port. Each role has a confidence and a short reasoning.

On a Kubernetes testbed, the Roles per IP table under the role summary also shows the pod behind each address, and what the pod's name says it is. The traffic still decides the role: when the pod agrees, the confidence is a little higher and the table says pod agrees; when it disagrees, a warning chip pod suggests … appears; for an address with no traffic evidence, suggested … shows the pod's role. Namespace filters the table. The same table appears in History (View Results) for captures taken while the pods were known.

RoleTypical evidence
AMFListens for NGAP (SCTP 38412); serves the namf SBI API
gNBConnects to the AMF over NGAP; GTP-U tunnel endpoint toward the UPF
SMF, UPFPFCP control side and user-plane side (UDP 8805), by message direction

9. When something goes wrong

What you seeWhat to do
Sent back to the login pageYour 8-hour login expired; log in again.
A yellow box: "Completed with problems"Part of the analysis failed; the listed parts are missing, the rest is valid. Try Re-run Analysis later, or tell your administrator.
Upload rejectedOnly .pcap file names are accepted, at most 5 uploads per minute.
Monitoring empty, or "Sensor is unreachable"The sensor is not running or not reachable; tell your administrator.
Real Time cannot connectThe sensor's port 5002 is not reachable from your computer, or the address changed.
A page keeps showing "Loading"Reload with Ctrl+F5.
